# Chess Tools

Terminal utilities for analyzing Chess.com account data, game archives, and performance metrics.

> **Note:** Executable scripts use `#!/usr/bin/env python3` for direct execution from your shell path. Adjust or invoke via `python <script>` as needed for your local environment.

## Overview

This repository contains standalone Python tools for chess data analysis. All executable scripts are located inside the [**`bin/`**](./bin) directory.

Example:
    chess-perf-eval.py --help

---

## Available Tools

All scripts are located in the [**`bin/`**](./bin) directory link above.
