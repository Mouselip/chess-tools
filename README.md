# Chess Tools

A collection of Python scripts for analyzing Chess.com account data, PGN archives, and player statistics.

## Included Tools

* **chess_archive_parser**: Downloads monthly PGN archives for a given username, extracts unique opponents, queries account statuses, and categorizes closed accounts.
* **wdl-history.py**: Parses game history to generate Win/Draw/Loss trends and breakdown metrics.
* **opponent-accuracy.py**: Analyzes opponent play metrics and performance accuracy across archives.
